TrendsIT 디자인 시스템 v1

최종 시안(홈 v01, 상세 한 열 + 미니 바 + 인용 툴팁)을 토큰과 컴포넌트 한 벌로 정리했습니다. 이 페이지도 같은 tokens.css와 trendsit.css로 그렸습니다. 정적 HTML + CSS, JS 없음.

원칙

  • 읽기 모드(홈·주차·토픽)와 관리 모드(소스·키워드·실행 기록)는 같은 토큰을 쓰고 밀도와 글자 크기만 다릅니다.
  • 무채색 + 형광 하나. 색만으로 뜻을 전하지 않고, 상태는 항상 글자로 씁니다.
  • Pretendard 하나, 굵기는 400과 500 두 가지. 위계는 크기와 색으로 먼저 만듭니다.
  • 간격은 4의 배수만 씁니다. 예외는 1px 선과 2px 포커스 테두리입니다.
  • 한국어 조판: 본문 16px 이상, 줄 간격 1.6, 자간 0, 단어 단위 줄바꿈(keep-all). 숫자·영문 토큰과 형광 구절은 줄에서 쪼개지 않고, 마지막 어절과 인용 번호는 붙여 둡니다.
  • 움직임은 인용 툴팁의 지연과 미니 바 등장 두 곳뿐입니다.
