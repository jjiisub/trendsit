CLI 출력을 표로, 사내 도구 정리 경험

한 팀이 사내 CLI 30여 개의 출력을 같은 표 형식으로 맞춘 경험을 공유했다. JSON 출력 옵션을 먼저 붙이고 표는 그 위에 그린 것이 핵심이다.

글 1

개요

출력 형식이 제각각인 CLI는 사람이 읽기도, 에이전트가 다루기도 어렵다. 글쓴이는 모든 명령에 JSON 출력을 먼저 붙이고 사람이 보는 표는 그 결과를 그리게 바꿨다. 이후 에이전트가 CLI를 호출할 때 출력 파싱 오류가 거의 사라졌다고 한다.

핵심 포인트

  1. 사내 CLI 32개에 --json 옵션을 먼저 추가하고, 표 출력은 같은 데이터를 그리도록 통일 [1]글 / 예시 블로그 / 10.3CLI 32개 출력을 표 하나로 맞춘 이야기예시 출처라 링크 없음출처 목록 [1]

  2. 에이전트 호출 시 출력 파싱 오류가 주 40여 건에서 1~2건으로 줄었다는 경험담 [1]글 / 예시 블로그 / 10.3CLI 32개 출력을 표 하나로 맞춘 이야기예시 출처라 링크 없음출처 목록 [1]
