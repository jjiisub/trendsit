## 2. 착수 순서

```
① 재료   code-reviewer 1회, 전체 코드. "명세" 자리에 AGENTS.md 원칙 + COMMON 6장 + prompt_guide 6.1
② 기획   /spec-plan docs/handoff/S5-1_TASK.md   (신규 모드. S5는 워크플로우 밖에서 구현돼 선행 런이 없다)
③ 실행   /impl-workflow docs/handoff/S5-1_TASK.md .
```

①은 구현에 넘기는 리뷰가 아니다. **②에서 "무엇을 뺄지" 사람이 고르는 질문 목록**이다.
Agent 도구로 `code-reviewer`를 직접 띄우고 이렇게 준다:

```
명세: AGENTS.md "원칙"·"함정", docs/handoff/COMMON.md 6장(6.1 포함), docs/reference/prompt_guide.md
대상: trendsit/ 전체, roles/*.md, skills/*.md, scripts/verify_s*.sh
보고서: .workflow/planning/s5-1/review-0.md
전부 보고하고 finding마다 영향 분류(정확성/명세위반/범위초과/품질/명세밖)를 붙여라.
특히: 같은 일을 하는 코드가 두 곳 이상인 것, 한 번만 쓰는 헬퍼·계층, 일어날 수 없는 상황의 방어 코드,
      설정 파일에 있지만 읽지 않는 키, 테스트가 경로 규칙을 다시 구현한 곳, 역할 md 간 중복 규칙.
```

## 3. 스펙에서 고르는 기준 — 빼기만

리뷰어는 지적을 찾으라고 하면 반드시 찾는다. 전부 쫓으면 과잉설계가 된다. 그래서:

- **기본값은 "안 한다".** 리뷰 finding 하나하나를 AC로 승격시킬지 사람이 고른다.
- **고르는 기준은 하나: 삭제로 해결되는가.** 추상화·계층·레지스트리·옵션을 추가해서 해결되는 지적은 제외한다.
  "공통 부모를 키운다"도 추가다. `artifacts_*` 세 파일의 공통화는 중복 삭제 범위에서만.
- 승격된 것만 수치 AC가 된다. 승격 안 된 `품질` 지적은 하지 않고, PR 설명에 목록만 남긴다.
- 실행 시간(94·115분 vs 목표 90분)은 **목표로 두지 않는다.** 목표로 두면 최적화 코드가 들어온다. 결과로 재기만 한다.

## 5. 불변식 후보

- **C-1** `bash scripts/verify_s5.sh` 종료 코드 0, pytest 건너뜀 0 (A1으로 s0~s4 포함)
- **C-2** 역할 호출 메시지(system + user)가 리팩터 전과 **바이트 단위로 동일**. 측정: 캐시 히트율 100%, 키 사용액 증가 0
- **C-3** `weekly --week 2026-W41` 출력(칠판 저장값·읽기본 md)이 리팩터 전 스냅숏과 동일(run_id·시각 제외)
- **C-4** `uv run python -m trendsit check-config` 통과, 역할 md 섹션 검사 통과
- **C-5** 각 CLI `--help` 출력이 스냅숏과 동일

C-2가 핵심 장치다. 프롬프트 조립 결과가 한 바이트라도 바뀌면 캐시가 깨져 비용이 들고 관문 B가 흔들린다. 코드로 재는 A등급 근거라 리뷰어도 반박 못 한다.

## 8. 기획에서 물을 것 / 묻지 않을 것

**물을 것(답이 달라지면 코드가 달라진다):**
- `checks.py` 사례별 규칙: 표 데이터로 바꿀지, 일부를 아예 뺄지(⚠ 발행으로 흡수), 그대로 둘지
- `artifacts_*` 중복: 삭제 가능한 범위가 어디까지인지(공통 부모 확장은 기본 "안 함")
- 500줄 파일 분할 기준과 새 파일 허용 수
- 순 삭감 목표 N, AC 승격할 리뷰 finding 목록
- 미사용 설정 키 4개: 지울지, S6 초안 칸으로 남길지

**묻지 않을 것(§12.1 구현 시점 기본값으로 위임 기록):** 이름 바꾸기, import 정리, 주석, 함수 순서, 타입 표기.

## 9. 실행 때 지킬 것

- 구현자는 예산을 넘길 것 같으면 **멈춘다.** "제대로 하려면 새 모듈이 필요하다"가 멈춤 신호고, 보통 답은 "그 항목은 빼자"다.
- `optional`(품질·명세밖)은 구현에 넘기지 않는다. S5-1은 품질 지적이 본체라, AC로 승격된 것만 한다.
- 게이트는 턴마다 3분(pytest 전체). 감당 가능하면 그대로. 15분을 넘기면 빠른 부분집합을 게이트로, 전체는 런 뒤 1회(COMMON 12장).
- 끝나면 `~/.claude/skills/spec-planner/references/lessons.md`에 "물었어야 했는데 안 물은 것 / 물었는데 안 물어도 됐던 것"을 적는다. v2 스킬의 첫 실사용이다.
