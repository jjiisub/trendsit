usage: trendsit [-h]

positional arguments:
  {check-config,role,eval,cost,trace,collect,items,report,rematch,filter,summarize,repo-analyze,plan,deep,filter-fixtures,video,weekly,select,write,review,cluster}
    check-config        설정 파일과 역할 정의 검증
    role                역할 1회 실행 또는 재생
    eval                픽스처로 실행 → 채점 → 리포트
    cost                스펙별, 모델별 사용액과 남은 예산
    trace               실행 1건의 걸음 목록
    collect             기간 수집(글, 유튜브, GitHub). RSS가 짧으면 백필
    items               수집 항목 목록
    report              리포트 생성
    rematch             바뀐 keywords.yaml로 저장된 항목의 키워드 판정을 다시 계산(네트워크 없음)
    filter              임베딩 관련성 필터(keep/drop) + 같은 URL 연결
    summarize           글 1차 요약(item_card): 필터 keep이고 같은 URL 기준 항목인 글
    repo-analyze        레포 분석가(repo_analyst): 규칙 기반 큐 또는 --queue 파일
    plan                편집장 계획(editor_plan): run(실행) / show(보기) / agreement(영상 mode 동의율)
    deep                깊게 보기: text(글 분석가, 원본 추적)
    filter-fixtures     eval/fixtures/filter 20건 점수(장치별 비교)
    video               영상 분석가(S4): 받기, 전사, 슬라이드 판독, 요약
    weekly              주간 브리핑(S5): 묶기 → 선별 → 작성 ⇄ 검수 → 저장 → 실행 요약 → 브리핑 읽기본
    select              주간 브리핑 단계(S5): 편집장 선별까지(현재판 묶기에서)
    write               주간 브리핑 단계(S5): 작성자 초안 + 코드 검사까지(검수자 없음)
    review              주간 브리핑 단계(S5): 현재판 초안부터 검사 ⇄ 검수 ⇄ 수정
    cluster             주간 묶기(S5): 근거 목록 → 표기 정규화 → 묶기 → 과거 대조 → 묶기 리포트

options:
  -h, --help            show this help message and exit
