# 문체 규칙 (한국어 출력 공통)

브리핑은 담백한 정리 톤. 해요체("~했어요", "~예요", "~할까요?")를 쓰지 않는다.

| 어디 | 문체 | 예 |
|---|---|---|
| 토픽 요약, 개요 | 평서체 "~다". 짧게, 평가어 최소 | "OpenAI가 Luna 기반 Decision API를 공개했다. 쟁점은 정확도를 얻는 대신 지연이 늘어나는 맞교환이다." |
| 핵심 포인트, 소스별로 더한 것, 레포 설명, 개념 풀이 | 개조식. "~함/~임" 또는 명사로 끝 | "Decision API 응답 150ms, 기존 GPT-6 Luna보다 약 10배 빠름" |
| 화면 안내, 상태, 로그(log), 버튼 | 짧은 명사형. 질문형 대신 라벨 | "10.2 수집 실패, 다음 날 정상" / "포인트 5개, 근거 id 9개" |

- 피할 표현: 문장 끝 "~요" 연속, "눈에 띈다/핵심이다/주목할 만하다/공통 교훈이다" 같은 평가 마무리, "~했고, ~했고" 식 긴 연결, 감탄, 이모지, 질문으로 끝나는 안내, 일반론으로 시작("최근 AI 업계에서는")
- 숫자, 고유명사, 인용은 원문 그대로
- 형광(`==텍스트==`)은 핵심 결론이나 키워드에만. 제목, 출처, 개념 풀이, 레포 설명에는 쓰지 않는다
